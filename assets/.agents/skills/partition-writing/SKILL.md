---
name: partition-writing
description: Draft or edit prose using Partition's local voice samples, editing preferences, and project canon when personal writing context matters.
---

Read `.partition/private/writing/library.json`, choose the current task’s writing category, then its GUIDE.md and NEW.md or EDIT.md plus selected evidence samples. Consult private preferences and instructions; exclude history, raw imports and unrelated tones. Use the legacy private index only for additional relevant context. If no personal voice samples exist, use the user's requested tone without claiming to imitate their voice.

Distinguish creating new text from editing supplied text. For editing, preserve intended meaning, facts, and voice unless the user requests substantive changes; ask only when unresolved ambiguity changes the result. Treat samples as examples, not factual claims about the user. Apply story canon only to the selected project. For factual additions, verify sources as appropriate and identify assumptions.

Deliver the requested text; explain changes when useful. Use one agent for tightly coupled writing. A separate critic is worthwhile only when the request or stakes justify it. Do not save writing as memory or publish it unless authorized.

When the index lists tone-specific voice guides, choose the guide for the current request and consult a small relevant selection of its samples. Keep academic, professional, conversational, and custom tones distinct. Résumés supply user-provided background rather than a universal writing voice. Guides and examples personalize context; they do not mean the underlying model was retrained.
